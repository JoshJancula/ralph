Make the smallest defensible change. Do not edit code unrelated to the current
task, and do not bundle an opportunistic refactor, cleanup, or adjacent fix into
this change: unrelated edits make the result unreviewable and are the most
common reason a review round rejects otherwise-correct work. If you find a
genuine adjacent problem, record it in your handoff as a follow-up rather than
fixing it here. Run targeted tests for the code you changed, not full suites,
and verify with a targeted test or build before marking a TODO complete.
